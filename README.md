# Web Design Academy

## Development

### Frontend

1. Set `VITE_GOOGLE_CLIENT_ID` in `./frontend/.env`

2. Run

```sh
cd frontend
npm install
npm run dev
```

### Backend

1. Set `GOOGLE_CLIENT_ID`, `ADMIN_EMAIL` and `JWT_SECRET` in `./backend/.env`

2. Run

```sh
cd backend
npm install
npm run start
```

## Docker

```sh
docker compose up
```
