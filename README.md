# Web Design Learning Application

## Usage

Front-end:

1. Set VITE_API_BASE and VITE_GOOGLE_CLIENT_ID in `./frontend/.env`

2. Run
```sh
cd frontend
npm install
npm run dev
```

Back-end:

1. Set GOOGLE_CLIENT_ID, ADMIN_EMAIL and JWT_SECRET in `./backend/.env`

2. Run
```sh
cd backend
npm run start
```
