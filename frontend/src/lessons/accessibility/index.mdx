# Accessibility Enhancements

## Task Instructions

1. **Form Labels**
  - Link the labels to their corresponding inputs by adding the proper `for` attribute that matches the input `id`.
  - Specify the correct semantic `type` for the email and password fields.
2. **Image Carousels**
  - Improve screen reader compatibility by giving the carousel wrapper a `region` role and an `aria-roledescription="carousel"`.
  - Add `aria-hidden` tags to the images based on visibility, and `aria-label` tags to the navigation buttons.
