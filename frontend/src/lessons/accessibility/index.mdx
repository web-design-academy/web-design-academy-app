# Accessibility Enhancements

## Task Instructions

1. **Form Labels**

   The sign-up form has three inputs (name, email, password) but no <C l="html">{"<label>"}</C> elements, so screen readers cannot identify what each field is for.

   For each input:
   - Add a <C l="html">{"<label>"}</C> element above it with descriptive text
   - Give the input an <C l="html">id</C> attribute
   - Set the label's <C l="html">for</C> attribute to match that <C l="html">id</C>
   - Make sure the email input uses <C l="html">{'type="email"'}</C> and the password input uses <C l="html">{'type="password"'}</C>

2. **Image Carousel**

   The carousel is visible on screen but missing accessibility metadata. Add ARIA attributes to describe its structure:
   - On the <C l="css">.carousel</C> wrapper: add <C l="html">{'role="region"'}</C>, <C l="html">{'aria-roledescription="carousel"'}</C>, and an <C l="html">aria-label</C> for the gallery name
   - On each <C l="html">{"<img>"}</C>: add an <C l="html">alt</C> description, set <C l="html">{'aria-hidden="false"'}</C> on the visible slide and <C l="html">{'aria-hidden="true"'}</C> on the hidden one
   - On the <C l="html">{"<label>"}</C> navigation buttons: add <C l="html">aria-label</C> attributes describing what each button does (e.g. <C l="html">{'aria-label="Go to first slide"'}</C>)
