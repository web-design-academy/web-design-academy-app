# HTML Basics

## Task Instructions

1. **Semantics**
  - Replace the generic `div` tags with appropriate semantic HTML5 tags (`<header>`, `<aside>`, `<main>`, `<section>`, `<footer>`).
2. **Images**
  - Insert an `img` element inside the image container.
  - Give it a valid `src` URL, an `alt` description, and set the `width` and `height` attributes directly on the tag.
3. **Typography**
  - Wrap the raw text using proper typographic elements like headings (`h1`, `h2`), paragraphs (`p`), emphasis (`strong`, `em`), small text, blockquotes, and citations.
4. **Links**
  - Turn the bracketed text into actual `<a>` tags.
  - Use internal links for the cards (e.g. `href="#card2"`), and add an external link with `target="_blank"` and a `title` attribute for the external site.
