# CSS Layout

## Task Instructions

1. **Mondrian painting**

- Add `background-color` properties to the Mondrian painting's color classes (`.red`, `.yellow`, `.blue`, `.white`, `.grey`) using standard hex codes.

2. **Layout & Spacing**

- Style the `main` container using Flexbox (column direction, gap, and margin).
- Add padding, border-color, border-radius, and a subtle drop shadow to the `.card` class.

3. **Hide the fish**

- Use Flexbox properties on the `#ocean` container (`display: flex`, `justify-content`, `align-items`) to center its child elements.
- The coral already has absolute positioning, so centering will cause the fish to hide directly behind the coral.
