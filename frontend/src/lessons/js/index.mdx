# JavaScript Interactivity

## Task Instructions

1. **Keyboard Movement**

- Add a `keydown` event listener to move the ball 10 pixels at a time (Up, Down, Left, Right).
- Calculate bounds using the game container size to ensure the ball never moves outside the boundaries.

2. **Quiz Verification**

- Add a click event listener to each `.option` button.
- Check the button's data attribute (`dataset.correct`) to verify the answer, and display "Correct!" in green or "Incorrect!" in red on the result display.
