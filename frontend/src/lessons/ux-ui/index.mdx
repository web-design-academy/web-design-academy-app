# UX/UI Principles

## Task Instructions

1. **Navigation Styling**
  - Style the structural navigation bar. Use list stylings, flexbox for horizontal gaps, distinct background colors, and apply a hover effect (e.g., underline) to the anchors. 
2. **Responsive Burger Menu**
  - Create a CSS-only hamburger menu using the hidden `#menu-toggle` checkbox hack.
  - Use a `@media` query to hide the normal navigation links on narrow screens (max-width: 600px), display the hamburger button instead, and only show the menu items when the checkbox is checked.
  - Make sure the page content visually reflows appropriately.
