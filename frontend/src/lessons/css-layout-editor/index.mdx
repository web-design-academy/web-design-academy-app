# Architektúra moderného webu

V tejto lekcii si prejdeš reálnymi scenármi z praxe. Tvojím cieľom bude premeniť neštýlované HTML bloky na moderné, responzívne komponenty.

### Čo ťa v tejto lekcii čaká?

Krok za krokom si poskladáme všetky dôležité časti webovej aplikácie:

1. **Navigačná lišta:** Zarovnanie loga, menu a tlačidla do jedného riadka (Flexbox).
2. **Hero Banner:** Vertikálne usporiadanie a natlačenie obsahu do rohu (Flex Direction).
3. **App Kostra:** Rozdelenie obrazovky na fixné menu a dynamický obsah (CSS Grid).
4. **Bento Box:** Vytvorenie modernej mriežky kariet s využitím funkcie `repeat()`.
5. **Featured Článok:** Roztiahnutie jedného prvku naprieč viacerými stĺpcami a riadkami (`span`).
6. **Záverečný Boss - Dashboard:** Prepojenie Gridu, Flexboxu a absolútneho pozíciovania notifikácií do jedného veľkého celku.
